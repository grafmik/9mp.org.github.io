# Apinya Estates

Site vitrine d'agent immobilier (Hua Hin, Thaïlande) — maquette de démonstration.

<https://9mp.org/apinya/>

Site statique en 4 pages, sans build ni dépendance : `index.html`,
`properties.html`, `about.html`, `contact.html` et `assets/`.

Le portfolio, les filtres et le tri fonctionnent ; le formulaire de contact
valide les champs mais n'envoie rien.

**Contenu d'exemple** — prix, coordonnées et témoignages sont fictifs.

Sources : dépôt [`aponya`](https://github.com/grafmik/aponya).
